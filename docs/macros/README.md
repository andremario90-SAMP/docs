## Convenzioni di Nomenclatura

### Prefissi Comando
- **B_**: Macro di CBase (geometria)
- **P_**: Macro di CPricesAndWeight (prezzi/pesi)
- **RFC_**: Macro di CRfcMain (refrigerazione)
- **LIB_**: Macro di CLib (libreria)
- **SEL_**: Macro di CSelector (selezione)
- **MSR**: Macro di CMSR (statistiche)
- *(nessun prefisso)*: Macro di CCommon (comuni)

### Stile Nomi
- **PascalCase**: Nomi macro (es. CoilHeight)
- **UPPERCASE**: Macro legacy (es. OPDIF, PROFILELEN)
- **camelCase**: Parametri e variabili interne
